Recipe Grid

Recipe blogs bury the recipe. Give this a link, pasted text, or a photo of a cookbook page and it returns a clean card: what to prep first, what you need, the steps, and a grid of which ingredient goes in at which step.

Some sites block automated requests. If a link fails, copy the recipe and use Paste text.
